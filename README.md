# ブラウザで遊べる対CPU将棋

インストール不要で遊べる、1人用のブラウザ将棋です。対局ごとに先手・後手がランダムに決まり、CPUが先手になった場合は自動で初手を指します。

## 今すぐプレイ

### [ブラウザで将棋AIに挑戦する](https://sinshu.github.io/vibe-coding-test/)

GitHub Pagesで公開しています。PC・スマートフォンのブラウザからアクセスできます。

## 特徴

- 盤上の駒をクリックして移動先を選ぶシンプルな操作
- 駒取り、持ち駒、駒打ち、成り、二歩禁止、王手放置禁止などのルールに対応
- 最終手と移動可能なマスをハイライト表示
- 対局ごとに先手・後手をランダムに決定
- 「反転」ボタンで盤面と持ち駒の配置を入れ替え可能
- CPUから見た形勢を絵文字で表示
- 対局終了後に棋譜をKIF形式でクリップボードへコピー
- PCの横長画面とスマートフォンの縦長画面に合わせたレスポンシブ表示
- バックエンドや外部ライブラリを使わない、単一HTML中心の構成
- 1手あたり2〜3秒を目安に局面を読む対局AI

## 遊び方

1. ページを開くと先手・後手が決まり、あなたが先手ならそのまま操作できます。CPUが先手なら初手を待ちます。
2. 自分の駒をクリックし、黄色く表示された移動先をクリックします。選択中の駒をもう一度クリックすると選択を解除できます。
3. 持ち駒を打つときは、自分の持ち駒欄から駒を選んで移動先をクリックします。
4. 成れる場所へ移動した場合は、確認画面で成るかどうかを選びます。
5. 対局終了後は「KIFをコピー」で棋譜をクリップボードに保存できます。
6. 視点を変えるときは「反転」、新しい対局を始めるときは「最初から」を押します。盤面の向きは新しい対局にも引き継がれます。

## AIについて

AIは固定的な手順ではなく、その場で合法手を生成して局面を探索します。

- 2〜3秒の探索時間内で、最大深さ7まで反復深化
- CPUが不利な局面では探索時間を3秒に延長
- αβ枝刈りによる先読み
- 置換表、キラー手、履歴ヒューリスティックによる探索効率化
- 取り合いを読み切るための静止探索
- 駒得、駒の働き、玉の安全、王手、持ち駒を考慮した局面評価
- 対局ごとに駒の相対価値が変わり、駒を惜しむ・積極的に交換するなど棋風が変化
- 飛車先の歩、角道、玉の移動、金銀と歩の壁を考慮した序盤・囲い評価
- 形勢、思考中、勝敗をCPUの表情で表示

## ローカルで遊ぶ

リポジトリをダウンロードし、`index.html`をブラウザで開くだけで起動できます。ビルドやパッケージのインストールは不要です。

```bash
git clone https://github.com/sinshu/vibe-coding-test.git
cd vibe-coding-test
```

## テスト

Node.jsが利用できる環境では、探索エンジンのスモークテストを実行できます。

```bash
node engine-smoke-test.cjs
```

テストでは、合法手と操作、先手・後手の開始処理、盤面反転、KIF棋譜の生成、対局ごとの駒価値、CPUの形勢表示と思考時間、自然な序盤の着手、囲いの評価、即勝ちの発見、駒得となる捕獲を確認します。

## 構成

- `index.html` — 画面、将棋ルール、AI探索エンジン
- `engine-smoke-test.cjs` — エンジンの自動スモークテスト
