# ブラウザで遊べる対CPU将棋

## 今すぐプレイ

[ブラウザで将棋AIに挑戦する](https://sinshu.github.io/vibe-coding-test/)

## 遊び方

1. 先手・後手はランダムに決まります。CPUが先手なら初手を待ってください。
2. 自分の駒をクリックし、黄色く表示された移動先をクリックします。同じ駒をもう一度クリックすると選択を解除できます。
3. 持ち駒は、持ち駒欄で選んでから打つ場所をクリックします。
4. 成れる場合は、確認画面で成るかどうかを選びます。
5. 「反転」で盤面の向きを変更し、「最初から」で新しい対局を始められます。
6. 対局終了後は「KIFをコピー」で棋譜を保存できます。

## CPUについて

適当なヒューリスティックの結果、なぜか右玉っぽい戦型と筋違い角が好きな棋風になったCPUです。たまに三間飛車をやります。

ハム将棋平手の難易度に満足できなくなった人向けです。
